# Railway Reservation System
A simple Python-based CLI application to manage train bookings.

## Features
* Check real-time seat availability.
* Book tickets with automated Booking ID generation.
* View ticket details using a unique ID.
* Cancel existing reservations.

## How to Run
1. Ensure you have Python installed.
2. Download `main.py`.
3. Run the command: `python main.py`
